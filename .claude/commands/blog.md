Summarize today's work for a blog post.

## Sources to check
- handoff/latest.md (current state)
- handoff/archive/ (completed tasks)
- git log --since="today" (today's commits)
- outputs/reviews/ (review results)
- outputs/plans/ (task plans)

## Output format
- Title: date + key topic
- One-line summary
- Work log (per completed Task — what was done and why)
- Learnings / retrospective (optional)
- Language: {{BLOG_LANGUAGE}} (default: Korean)
- Tone: dev blog, casual

## Save to
