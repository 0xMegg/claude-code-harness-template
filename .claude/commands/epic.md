Run the Epic automation script.
This decomposes an Epic into Slices, then runs Plan → Develop → Review for each Slice automatically.

## Instructions
Run the following command and wait for it to complete:

```bash
./scripts/run-epic.sh $ARGUMENTS
```

Do NOT do anything else. Just run the script and report the result.
If the script fails at a Slice, show which Slice failed and the relevant log output.
